# AI Agent for Odontology Clinics

Agente de IA para WhatsApp que atende pacientes de clínicas odontológicas fora do horário comercial: triagem de urgência (texto e áudio), orientação segura em emergências e agendamento autônomo integrado a um sistema de agenda próprio, com atualização em tempo real no painel da doutora.
